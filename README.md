# Projeto do Portfólio

Este repositório contém os arquivos do meu portfólio estático.

Como publicar:

1. Inicialize o git localmente:
   - `git init`
   - `git add .`
   - `git commit -m "Primeiro commit"`
2. Crie um repositório remoto no GitHub e rode:
   - `git remote add origin https://github.com/SEU_USUARIO/SEU_REPO.git`
   - `git branch -M main`
   - `git push -u origin main`
3. Para publicar como site estático use GitHub Pages nas configurações do repositório (branch `main`, pasta `root`).

Sincronizar localmente:

- Sempre rodar `git pull` antes de começar a editar.
- Use `git add`, `git commit`, `git push` para enviar alterações.

Se quiser, posso ajudar a criar o repositório GitHub e ativar o Pages (você precisará autorizar com o `gh` ou credenciais).
